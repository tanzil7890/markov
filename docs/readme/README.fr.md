**Aussi dans la boîte :**

- **[Quick open](https://markov.outhad.com/docs/model/quick-open)** — Cherchez parmi worktrees, fichiers, agents, commandes et contexte du repo sans quitter votre flow.
- **[Sélecteur de comptes &amp; suivi d'usage](https://markov.outhad.com/docs/agents/usage-tracking)** — Suivez l'usage Claude et Codex et les resets de rate limit, et basculez de compte à chaud sans vous reconnecter.
- **[Aperçus riches du repo](https://markov.outhad.com/docs/editing/markdown)** — Prévisualisez Markdown, images, PDF et docs du repo dans le workspace.
- **[Computer Use](https://markov.outhad.com/docs/cli/computer-use)** — Laissez les agents piloter des apps desktop et l'UI visible quand un workflow demande une vraie interaction.
- **[Notifications et non-lus](https://markov.outhad.com/docs/notifications)** — Sachez quand un agent termine ou a besoin d'attention, puis marquez des fils comme non lus pour y revenir plus tard.

## Installation

### Desktop — macOS, Windows, Linux

- **[Télécharger depuis markov.outhad.com](https://markov.outhad.com/download)**
- Ou récupérez un build directement : [macOS Apple Silicon](https://github.com/tanzil7890/markov/releases/latest/download/markov-macos-arm64.dmg) · [macOS Intel](https://github.com/tanzil7890/markov/releases/latest/download/markov-macos-x64.dmg) · [Windows (.exe)](https://github.com/tanzil7890/markov/releases/download/v1.4.147-rc.3/markov-windows-setup.exe) · [Linux AppImage](https://github.com/tanzil7890/markov/releases/latest/download/markov-linux.AppImage) · [Tous les builds](https://github.com/tanzil7890/markov/releases/latest)
- **Sous Windows :** utilisez la [dernière RC (`v1.4.147-rc.3`)](https://github.com/tanzil7890/markov/releases#release-v1.4.147-rc.3) — elle inclut des correctifs Windows absents de la stable.

_Ou via un gestionnaire de paquets :_

```bash
# macOS (Homebrew)
brew install --cask tanzil7890/markov/markov
# Mettre à jour une installation existante
brew upgrade --cask tanzil7890/markov/markov
```

### Companion mobile — iOS, Android

Associez-la à l'app de bureau pour surveiller et piloter vos agents depuis votre téléphone.

- **iOS :** [Télécharger sur l'App Store](https://markov.outhad.com/download/ios)
- **Android :** [Télécharger l'APK](https://markov.outhad.com/download/android)
