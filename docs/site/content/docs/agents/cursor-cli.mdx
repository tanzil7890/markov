---
title: Cursor CLI in Markov
---

Cursor CLI is Cursor's command-line agent. Markov runs it with first-class support — launch from the combobox, full OSC state detection, and restart chip on exit.

## Setup

1. Install Cursor CLI per [Cursor's docs](https://cursor.com/cli).
1. Log in once.
1. Markov auto-detects the CLI on `PATH`.

## Launching

Pick **Cursor** from the combobox. Markov launches the CLI scoped to the worktree. Cursor's TUI emits the state events Markov needs for agent state dots.

## Model selection

Model selection is driven by Cursor's own settings. Markov doesn't override it — configure inside the CLI.
