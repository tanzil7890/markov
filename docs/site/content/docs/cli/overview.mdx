The Markov CLI is the `markov` command-line interface for scripting a running Markov editor from any shell. Use it to create and inspect worktrees, drive agent terminals, open files and diffs, automate the built-in browser, run scheduled automations, share HTML/Markdown artifacts, and control Markov-native tools from scripts or AI agents.

It ships with the desktop app; register it under [Settings → General → Markov CLI](/docs/settings). On Linux the command is `markov-ide` — see [Install → Linux](/docs/install#linux).

Agents can install the matching Markov CLI skill with:

```bash
npx skills add https://github.com/tanzil7890/markov --skill markov-cli
# headless / no Settings UI:
markov skills install --skill markov-cli
```

See [Skills registry & MCP](/docs/cli/skills) for every installable Markov skill, including `markov skills install` / `markov skills update`.

## Install & verify

```
command -v markov
markov status --json
```

## Worktree commands

```
markov worktree ps --json
markov worktree create --repo id:<repoId> --name my-task --issue 123 --json
markov worktree create --repo id:<repoId> --name review-pr-123 --pr 123 --json
markov worktree current --json
markov worktree set --worktree active --comment "reproduced bug" --json
markov worktree set --worktree active --gitlab-issue 42 --gitlab-mr 77 --json
markov worktree set --worktree active --pr null --json
markov worktree rm --worktree id:<id> --force --json
```

For selectors, setup flags, parent/child worktrees, and the broader command map, see [Markov CLI reference](/docs/cli/reference).

## Terminal commands

```
markov terminal list --json
markov terminal read --json
markov terminal send --text "continue" --enter --json
markov terminal wait --for tui-idle --timeout-ms 30000 --json
markov terminal create --worktree path:/projects/app --command "npm test" --json
markov terminal split --direction vertical --command "npm run dev" --json
```

For tracked multi-agent work, use [Orchestration](/docs/cli/orchestration) instead of plain terminal prompts.

## File commands

Open files and diffs as tabs in their Markov worktree from a shell. They open without changing what you are looking at; add `--focus` to be brought to the file:

```
markov file open src/App.tsx
markov file diff src/App.tsx --staged
markov file open-changed --mode both
```

Use `--worktree <selector>` when the shell's current directory is not inside the target worktree.

## Browser profiles

Browser profiles isolate tab session state, so a script or agent can test with different cookies, local storage, and logged-in identities. The CLI exposes profile commands under `markov tab profile`; start with `markov tab profile list --json`, then use `create`, `set`, `clone`, or `use-default` as needed.

## Scheduled automations

Use `markov automations` to create, inspect, run, and remove scheduled Markov tasks from a shell. Start with [Scheduled automations](/docs/cli/automations) when you want a recurring prompt to run against a repo or an existing worktree.

## Artifacts

Share HTML or Markdown as public view links through the signed-in Markov account (`markov artifacts share|update|list|delete`). Publishing is **opt-in** under Settings → Artifacts. Command details: [CLI reference → Artifacts](/docs/cli/reference#artifacts).

## Browser automation

The CLI also drives the built-in browser with a snapshot-interact-re-snapshot loop:

```
markov goto --url https://example.com --json
markov snapshot --json     # returns refs like @e1, @e3
markov click --element @e3 --json
markov fill --element @e1 --value "user@example.com" --json
markov screenshot --json
```

For responsive browser checks, switch the active tab to a named device profile:

```
markov set device --name "iPhone 12" --json
markov screenshot --json
```

## Mobile emulator

The CLI can also drive an iOS Simulator through Markov's mobile emulator bridge. It is scoped to the active worktree, so agents and scripts can attach a simulator, list the worktree's attached devices with `markov emulator list`, tap normalized coordinates, type text, send gestures, rotate the device, and shut it down without leaving Markov.

```
markov emulator list --json
markov emulator attach "<device-name-or-udid>" --json
markov emulator tap 0.5 0.7 --json
markov emulator type "hello" --json
markov emulator gesture '[{"type":"begin","x":0.5,"y":0.8},{"type":"move","x":0.5,"y":0.4},{"type":"end","x":0.5,"y":0.2}]' --json
markov emulator rotate landscape_left --json
markov emulator kill --json
```

Use `--worktree <selector>`, `--device <udid-or-name>`, or `--emulator <id>` when a script needs an explicit target.
